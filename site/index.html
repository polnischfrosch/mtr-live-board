Live Transit Boards

Test benches for the LED map boards: live data, the same logic as the firmware, two LEDs per station.

Hong Kong 港鐵

All 10 MTR lines, 236 LEDs. Data from the MTR Next Train API.

Stuttgart

U1, U14, U2 and buses 92 and 81, 39 stops. Data from the VVS departure monitor.

Source code, tests and the command-line tool: github.com/polnischfrosch/mtr-live-board
