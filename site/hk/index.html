Two LEDs per station, one per direction. MTR trains run on the left, so each LED sits on the left of its direction of travel. A train fades in from dim as it leaves the station before and reaches full brightness at the platform. Click a station for its next trains.

Click a station on the map.

Every request this page made, newest first. The debug file has the same shape as the one from mtr_live_test.py, so it can be checked the same way. It contains no location or personal data.

Connection

The page asks MTR directly from your browser. A browser only lets the page read the answer if the service allows it (CORS). If the test below says blocked, put the address of your proxy here (a free Cloudflare Worker, see worker/README.md in the repository) and tick the box.
